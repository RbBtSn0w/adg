PROJECT SETUP
# Install ADG
npm install -g @rbbtsn0w/adg

# Add one skill; register with Codex
adg plugins add obra/superpowers --ref main \
  --only skills --skill brainstorming \
  --target codex --project

# Connect Claude Code
adg plugins link --target claude --project

# Verify each runtime
adg plugins status --target codex --project
adg plugins status --target claude --project

Want the same store across projects? Use --global consistently instead of --project.

Before you try it

A few practical details.

Which agents and components are supported?

ADG connects to Codex and Claude Code through their native plugin CLIs, and generates Antigravity projections. Component support differs by runtime; unsupported components may be skipped with warnings. Check the compatibility specification before depending on a particular hook or MCP behavior.

Does my plugin repository need a new manifest?

Existing Claude and Codex plugin manifests can be imported. A manifest-free source can use standard skills, hooks, and MCP locations. Multi-plugin repositories have additional discovery requirements; see the source layout guide.

What does project scope mean?

The managed store belongs to the current project. Agent CLIs may also maintain their own registries and caches. Use --project on every command for that store; use --global consistently for a shared store. Project scope is not a security sandbox for plugin code.

How do updates and state checks work?

Run adg plugins update --project to refresh a project store, then inspect each runtime with status. Status checks names and registration, not skill content or execution. Read the update and recovery guide for selection, disabled-state, and repair behavior.

Does ADG collect telemetry?

By default, ADG sends anonymous OpenTelemetry command names, outcomes, and timings to a maintainer-run gateway. Argument values are redacted. Set DO_NOT_TRACK=1, DISABLE_TELEMETRY=1, or OTEL_SDK_DISABLED=true to opt out. See the full disclosure. This static site adds no analytics script.

How can I report a first-try problem?

Share the ADG and agent versions, operating system, command with private values removed, chosen scope, and expected versus observed result in a GitHub issue. Remove tokens, usernames, private paths, repository names, and credentials before posting. Successful first tries are useful feedback too.
